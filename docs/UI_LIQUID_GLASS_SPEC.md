# StayWorth 前端视觉规范：Liquid Glass 暗色奢华版

日期：2026-09-28
范围：首页首屏（Hero）、流体玻璃预订面板、全站材质与排版令牌。

## 0. 设计读解与旋钮

- **Design Read**：面向"这次入住，现金还是积分更值"的中文旅客的高端住宿决策工具，采用 Apple Liquid Glass 暗色奢华语言，Tailwind v4 工具类加少量材质 CSS 近似实现。
- **诚实标注**：Apple 只为 Apple 平台定义 Liquid Glass，网页端没有官方 CSS 包。本方案是 `backdrop-filter` + 分层描边 + 高光叠层的网页近似，代码注释里已写明。
- **旋钮**：`DESIGN_VARIANCE 8`（非对称编辑式排版）/ `MOTION_INTENSITY 5`（流体 CSS 动效，不做滚动劫持）/ `VISUAL_DENSITY 4`（决策工具需要可读密度）。
- **主题锁定**：全站暗色，不做区块反色。

## 1. 第一阶段：流体视觉规范

### 1.1 色彩令牌

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--obsidian-900` | `#05070B` | 页面底色（黑曜石，非纯黑） |
| `--obsidian-800` | `#080B12` | 深层面板 |
| `--obsidian-700` | `#0B0F18` | 抬升层 |
| `--glass-panel` | `rgba(6,9,15,0.82)` | 预订面板 / 大面积玻璃 |
| `--glass-card` | `rgba(8,11,18,0.72)` | 卡片玻璃 |
| `--glass-quiet` | `rgba(11,15,24,0.66)` | 次级分区、条目玻璃 |
| `--titanium` | `#F7F8FA` | 正文与标题纯色文字 |
| `--titanium-dim` | `#C7CDD8` | 次级文字 |
| `--steel` | `#98A1B0` | 辅助说明文字 |
| `--champagne` | `#E3C88F` | 唯一点缀色：描边、图标、数值高亮 |
| `--champagne-solid` | `#EBD5A7` | 实体 CTA 底色 |
| `--ink-on-gold` | `#14100A` | CTA 上反色文字 |
| `--alert` | `#FFA79B` | 错误文字与错误描边 |

对比度实测（玻璃 0.72 叠加底色后的等效背景约为 `#080B12`）：

- 正文 `#F7F8FA` ≥ 17:1
- 次级 `#C7CDD8` ≈ 12:1
- 辅助 `#98A1B0` ≈ 7.4:1
- 香槟金文字 `#E3C88F` ≈ 11.9:1
- CTA `#EBD5A7` 底 + `#14100A` 字 ≈ 13:1

全部高于 WCAG AA 的 4.5:1。正文、价格、按钮文字一律纯色，不加模糊、透明度或辉光。

### 1.2 毛玻璃参数（Tailwind 与 CSS 对应）

| 层级 | 背景 Alpha | 模糊 | Tailwind 写法 |
| --- | --- | --- | --- |
| 面板 | 0.82 | `blur(28px) saturate(150%)` | `bg-[rgba(6,9,15,0.82)] backdrop-blur-[28px] backdrop-saturate-150` |
| 卡片 | 0.72 | `blur(20px) saturate(140%)` | `bg-[rgba(8,11,18,0.72)] backdrop-blur-[20px] backdrop-saturate-140` |
| 条目 | 0.66 | `blur(12px) saturate(130%)` | `bg-[rgba(11,15,24,0.66)] backdrop-blur-[12px]` |

玻璃层 Alpha 一律不低于 0.6：流动光晕在卡片后面经过时也不会吃掉文字轮廓。
`prefers-reduced-transparency: reduce` 时退回 0.94 实质背景并关闭模糊。

### 1.3 1px Liquid 描边（高光边缘）

用于容器 `::before`，1px 环，`mask-composite: exclude` 挖空内部：

```css
linear-gradient(
  135deg,
  rgba(255, 255, 255, 0.55) 0%,
  rgba(227, 200, 143, 0.34) 22%,
  rgba(255, 255, 255, 0.10) 48%,
  rgba(152, 161, 176, 0.16) 72%,
  rgba(255, 255, 255, 0.42) 100%
)
```

聚焦 / 激活态换成更亮的一条，并叠一层外发光：

```css
linear-gradient(
  135deg,
  rgba(255, 255, 255, 0.78) 0%,
  rgba(235, 213, 167, 0.62) 30%,
  rgba(255, 255, 255, 0.28) 62%,
  rgba(235, 213, 167, 0.70) 100%
);
box-shadow: 0 0 0 1px rgba(235, 213, 167, 0.35), 0 0 28px -6px rgba(235, 213, 167, 0.45);
```

文字控件另保留 3px 实体 outline（`outline: 3px solid var(--champagne)`），键盘焦点在任何背景上都可见。

### 1.4 多层深度阴影

```css
--shadow-liquid:
  inset 0 1px 0 rgba(255, 255, 255, 0.14),
  inset 0 -1px 0 rgba(255, 255, 255, 0.04),
  0 1px 1px rgba(0, 0, 0, 0.45),
  0 12px 28px -14px rgba(0, 0, 0, 0.72),
  0 42px 90px -42px rgba(0, 0, 0, 0.92),
  0 80px 160px -80px rgba(227, 200, 143, 0.12);
```

悬停抬升态再叠一层近景阴影 `0 8px 20px -10px rgba(0,0,0,0.7)` 并 `translateY(-2px)`。

### 1.5 字号层级

| 层级 | 字号 | 行高 | 字距 | 字体 |
| --- | --- | --- | --- | --- |
| `display-xl` | `clamp(2.6rem, 4.6vw, 4.25rem)` | 1.02 | `-0.02em` | 衬线（Didot / Bodoni 72 / Songti SC） |
| `display-l` | `clamp(1.9rem, 2.6vw, 2.6rem)` | 1.1 | `-0.02em` | 衬线 |
| `display-m` | `1.5rem` | 1.2 | `-0.01em` | 衬线 |
| `body-l` | `1.0625rem` | 1.75 | 0 | 苹方 / 系统无衬线 |
| `body` | `0.9375rem` | 1.7 | 0 | 苹方 / 系统无衬线 |
| `data` | `0.8125rem` | 1.5 | `0.02em` | 等宽 + `tabular-nums` |
| `label` | `0.6875rem` | 1.4 | `0.26em` | 等宽大写 |

衬线选择理由：酒店业是少数真正属于编辑 / 奢华语境的行业，暖纸张与黄铜不在本方案里，改用黑曜石底上的 Didot 系衬线；中文用宋体（Songti SC）呼应。数字与标签走等宽，形成仪表盘式精确感。

### 1.6 圆角与动效

- 圆角规则：容器 28-32px，输入框 16px，按钮与徽标为胶囊。全站只用这三档。
- 动效：`transition: all 300ms cubic-bezier(0.16, 1, 0.3, 1)`；只动 `transform` 与 `opacity`。
- 背景流动光圈：26-34s 缓慢位移，`prefers-reduced-motion: reduce` 时全部静止。
- 光晕：3 个超大半透明径向渐变，低饱和度（香槟金 0.10、钢蓝 0.12、深青 0.08），固定在视口层，`pointer-events: none`。

### 1.7 可用性红线（覆盖视觉偏好）

1. 正文、价格、按钮文字禁用任何模糊、发光、半透明效果。
2. 玻璃容器 Alpha ≥ 0.6。
3. 核心 CTA 使用实体香槟金，不用毛玻璃。
4. 预订表单保持线性直觉顺序：目的地、入住、退房、品牌层级、出行人数、积分兑换开关、提交。

## 2. 第二阶段：布局蓝图

### 2.1 Hero 非对称流体排版

桌面（≥1024px）12 列栅格，行不留空：

```
+--------------------------------------------------------------+
| 顶栏（68px，单行，玻璃贴合）                                  |
+--------------------------------------------------------------+
| 左栏 7 列                      | 右栏 5 列（下沉 56px）       |
| 眉标 12px 等宽香槟金           | 液滴玻璃卡                   |
| 衬线大标题 2 行                |  - STAYWORTH INDEX 标签      |
| 副文案 ≤ 20 词 / ≤ 2 行        |  - ¥395.98 主数值（等宽）    |
|                                |  - P25 / P75 区间            |
|                                |  - 样本城市数与日期脚注      |
+--------------------------------------------------------------+
| 预订面板（跨 12 列，向上压住 Hero 底边 48px）                 |
| 目的地 | 入住日期 | 退房日期 | 品牌层级 | 出行人数 | 积分开关 | CTA |
+--------------------------------------------------------------+
```

留白策略：左栏标题占满 7 列但文字宽度锁在 `31ch` 以内，右栏卡片下沉 56px 制造非对称重心；Hero 上下内边距控制在 `pt-20 / pb-28`，大标题不超过 2 行，预订面板在 1440×900 首屏内完整可见（含 CTA）。

移动端（<1024px）：严格单列，卡片移到标题下方，预订面板字段 1 列，CTA 全宽，光晕不透明度降到 0.6 倍避免抢文字。

### 2.2 预订面板

- 面板本身是玻璃（0.82 + 28px 模糊），字段是次级玻璃（0.66），CTA 是实体香槟金。
- 字段顺序固定为旅行直觉顺序，不做艺术化重排。
- 聚焦时字段的 1px 环变亮并出现香槟金外发光，标签同步变亮，保证键盘用户始终知道焦点在哪。
- 校验错误在字段下方以 `role="alert"` 出现，输入框 `aria-invalid` + `aria-describedby` 关联，描边转 `--alert`。
- 提交按钮实体金，`:active` 下沉 1px，`:disabled` 降为 0.45 不透明度，文字仍保持纯色。
