# Low-Fidelity Prototype Acceptance Criteria

## Purpose

This document defines what a user must be able to see and do before the first
StayWorth prototype is considered complete.

## Hotel Comparison

- The user can switch to the Hotel Comparison module.
- The search form contains destination, check-in date, check-out date, and
  current Marriott portfolio tier.
- Search results use mock data and clearly say that they are not live prices.
- Le Méridien Hong Kong, Cyberport is shown with:
  - CNY 1,235 cash price;
  - 37,000 Marriott points;
  - CNY 333.78 value per 10,000 points.
- The user can select between two and four hotels for comparison.
- A comparison view explains the calculation rather than showing only a score.

## Points Rebate Calculator

- The user can switch to the Points Rebate Calculator module.
- The form includes cash price, member tier, card multiplier, welcome points,
  promotional points, and custom point valuation.
- The result shows total points earned, estimated rebate value, and net stay
  cost.
- The result includes a visible calculation breakdown.

## Quality

- The interface works at desktop and mobile widths.
- Interactive controls have accessible labels.
- The project builds successfully.
- Formula tests and server-rendering tests pass.

## Non-Goals

- Live Marriott data
- User accounts
- Booking
- Alerts or price monitoring
- Final visual branding
